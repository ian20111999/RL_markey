⚙️ CONFIGURATION
═══════════════════════════════════════════════════════════════════════════════

Main config file: configs/pipeline_config.yaml

Key settings:
─────────────
pipeline:
  max_retries: 5              # Maximum retry attempts
  total_timesteps: 200000     # Training steps
  early_stopping: true        # Stop when good result found
  cleanup_failed_runs: true   # Clean up failed runs

auto_tuning:
  enabled: true               # Enable auto parameter tuning
  spread_ratio: 0.0005        # Spread ratio (0.05% = 5 bps)
  cash_multiplier: 10.0       # Initial cash multiplier

training_acceptance:
  min_pnl: 0
  min_win_rate: 0.45
  min_sharpe: 0.0

production_readiness:
  min_sharpe: 0.5
  min_win_rate: 0.48
  min_profit_factor: 1.2

🐛 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Training Always Fails
─────────────────────
→ Lower training_acceptance thresholds
→ Increase max_retries
→ Check data quality
→ Reduce total_timesteps for faster iteration

Web Dashboard Not Working
──────────────────────────
→ Ensure Flask installed: pip install flask flask-cors
→ Check if server running: ps aux | grep web_dashboard
→ Check port availability: lsof -i :5000

Out of Memory
─────────────
→ Reduce eval_episodes
→ Reduce total_timesteps
→ Don't use --parallel
→ Train fewer symbols at once

Poor Model Performance
──────────────────────
→ Increase total_timesteps
→ Use hyperparameter search
→ Adjust reward function
→ Improve data quality
